# Novis — Landing Website

Public landing page for **Novis**, the anonymous stranger-connect app:
text chat, voice calls and video calls with strangers. No signup, 18+ only, free.

🌐 Live site: https://fsix7115-arch.github.io/novis-web/

This repository contains only the static website (plain HTML/CSS/JS, no build step).
Download buttons point to `releases/android`, `releases/windows` and `app/` and are
wired to the real app artifacts separately.
